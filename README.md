# flint

A small system monitor for the terminal


## Build

    make             
    make install      # /usr/local/bin as root, otherwise ~/.local/bin
    make uninstall

Press `?` inside flint to see the keys, `q` to quit.

## Configuration

`~/.config/flint/flint.ini` .
